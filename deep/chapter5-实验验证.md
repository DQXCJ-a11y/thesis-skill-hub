# 第五章 · 实验验证 · 深度审查包

> 使用方法：将本文件粘贴给已激活SKILL的AI，发送"请用这份深度审查包对我的第五章进行逐段审查"。

---

## 一、第五章的定位

第五章是"用数据说话"的章节。核心任务：通过实验验证第3、4章方案的有效性，证明研究目标已达成。

**写作逻辑：** 实验目标 → 实验环境/平台 → 实验方案设计 → 实验结果 → 结果分析

**硬约束：** 每组实验都必须有明确的验证对象，对应第3章或第4章的某个设计点。

---

## 二、实验平台审查

### 2.1 完整性检查

| 要素 | 内容 | 缺失标记 |
|------|------|---------|
| 硬件设备 | 型号 + 主要指标 | 🔴 |
| 软件环境 | 名称 + 版本 | 🔴 |
| 数据来源 | 自采/公开数据集/仿真信号 | 🔴 |
| 连接方式 | 各设备之间如何连接（如有硬件） | 🟡 |
| 参考基准 | 独立参考设备（如万用表、标准仪器） | 🟡 |

### 2.2 实验平台图/照片

- [ ] 是否有实验平台照片或连接示意图？
- [ ] 图片是否清晰？
- [ ] 图注是否完整？

## 三、每组实验四要素审查（逐组检查）

**这是第五章最核心的审查。对每一组实验逐一检查：**

| 要素 | 内容 | 缺失时的标记 |
|------|------|-----------|
| ① 实验目的 | 本实验验证什么？对应第3/4章哪个设计？ | 🔴 |
| ② 实验设置 | 参数设定、测试条件、输入信号 | 🔴 |
| ③ 实验结果 | 数据/图/表 | 🔴 |
| ④ 结果分析 | **为什么出现这个结果** | 🔴 最容易缺失 |

### 3.1 实验目的检查

建立对应关系表：

| 实验编号 | 实验名称 | 对应第3/4章哪个设计 | 是否明确对应 |
|---------|---------|-------------------|-----------|
| 5.x.x | [实验名] | 第X.X节 | 是/否 |

**🔴 如果某组实验找不到对应的设计点 → 实验与设计脱节**
**🔴 如果某个设计点没有对应的实验 → 验证不完整**

### 3.2 结果分析深度审查（最严格）

结果分析应达到以下四个层次中的至少前三个：

| 层次 | 内容 | 缺失标记 |
|------|------|---------|
| ① 描述结果 | 简述数据/图的基本情况 | 🔴 |
| ② 解释原因 | 从机理/设计角度解释为什么有这个结果 | 🔴 |
| ③ 评价性能 | 与对比基准比较，是否满足设计目标 | 🔴 |
| ④ 指出局限 | 在什么条件下性能会下降 | 🟡 |

**🔴 "只呈现数据不分析"是第五章最常见最严重的不足。** 如果某组实验贴出图表后直接换节，没有分析段 → 必须修改。

**合格的分析段模板：**
```
由[图/表]可见，[观察到的现象/数据]。
这表明[方案/算法]能够有效[功能]，[误差/性能指标]满足[设计目标/标准限值]。
与[对比方法/基准]相比，[指标A]提升了……，主要原因在于……。
值得注意的是，在[特定条件]下，[某指标]出现了[现象]，
这与[原因分析]有关，在后续工作中可通过[改进思路]加以优化。
```

## 四、对比基准审查

| 检查项 | 合格标准 | 不合格标记 |
|--------|---------|----------|
| 是否有对比 | 至少与一种基准进行比较 | 🔴 无对比 |
| 对比是否公平 | 相同条件下比较 | 🔴 条件不同 |
| 基准来源 | 已有方法/行业标准/理论值/参考仪器 | — |

---

## 五、数据完整性与自洽性审查

| 检查项 | 方法 | 不合格标记 |
|--------|------|----------|
| 占位符检查 | 搜索"待填入""待补充""TODO""??" | 🔴 |
| 数据自洽 | 摘要数据 = 正文数据 = 总结数据 | 🔴 不一致 |
| 边界条件 | 是否测试了极端/边界情况 | 🟡 |
| 数据合理性 | 数据是否过于完美（无任何偏差） | 🟡 可疑 |
| 重复性 | 是否有多次重复测量 | 🟡 |

## 六、图表质量审查

| 检查项 | 合格标准 | 不合格标记 |
|--------|---------|----------|
| 图片清晰度 | 300dpi以上或矢量图 | 🔴 模糊 |
| 图注完整性 | 每张图/表有编号和说明 | 🔴 缺图注 |
| 坐标轴标注 | 有单位、有刻度 | 🟡 |
| 表格格式 | 三线表，表题在表上方 | 🟡 |
| 正文对应 | 每张图/表在正文有引用和分析 | 🔴 贴了图但没分析 |

## 七、本章小结审查

须按每组实验逐一总结：

```
本章搭建了[实验平台]，针对[场景]开展了[X]类验证实验。
（1）[实验A]结果表明，[结论A]，满足[标准/目标]。
（2）[实验B]结果表明，[结论B]，[指标]达到……。
综合上述实验结果，验证了本文提出的[方案]在[性能维度]上的有效性。
```

## 八、完整错误清单

| # | 错误类型 | 错误表现 | 正确做法 |
|---|---------|---------|---------|
| 1 | 实验与设计脱节 | 实验内容与第3/4章无对应 | 每组实验对应一个设计点 |
| 2 | 只展示不分析 | 贴图表后直接换节 | 每组实验有分析段 |
| 3 | 无对比基准 | 只展示自己的结果 | 与基准进行比较 |
| 4 | 图表无说明 | 图注过简或缺失 | 完整图注+正文分析 |
| 5 | 数据不自洽 | 摘要与正文数据不同 | 全文数据统一核对 |
| 6 | 数据过于完美 | 所有实验结果都很好 | 如实呈现偏差并解释 |
| 7 | 缺边界测试 | 只测正常工况 | 测试极端/边界条件 |

## 九、实操经验提示

- **实验章是审稿人判断论文"真不真"的关键。** 数据必须真实，分析必须有深度。
- **"没有功劳也有苦劳"不适用于实验章。** 做了很多实验但分析不深入，不如少做几组但每组分析透彻。
- **对比基准的选择：** 优先选择同领域公认的方法或国家标准，其次是理论值，最后是参考仪器。
- **实验数据有偏差是正常的。** 关键是你能不能解释偏差的来源。能解释 = 理解透彻；不能解释 = 你可能不理解自己的系统。
