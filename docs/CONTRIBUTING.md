# 贡献指南

感谢你对 Thesis Skill Hub 的关注！欢迎提交 Issue 和 Pull Request。

---

## 可以贡献什么

### 1. 改进现有 SKILL 内容
- 发现规则有误或遗漏
- 有更好的改写策略或审查规则
- 发现某些表述在特定 AI 平台上效果不好

### 2. 提交新的来源
- 发现优秀的论文写作相关开源项目
- 提供可参考的审查清单或写作规范

### 3. 分享使用反馈
- 在特定 AI 平台上的测试结果
- 实际使用中发现的问题
- 改进建议

### 4. 补充示例
- 不同学科的使用示例
- 不同 AI 平台的效果对比

---

## 提交 PR 的规范

### SKILL 文件格式要求

每个 SKILL 文件应包含：
1. **标题和角色定义**：你是……，你的任务是……
2. **工作原则**：3-5 条核心原则
3. **具体规则/流程**：可操作的检查清单或步骤
4. **输出格式**：明确定义输出的结构
5. **开始工作**：引导用户开始的入口语

### 命名规范

- SKILL 文件名：`XX-功能名称.md`（XX 为两位数编号）
- 文档文件名：英文小写，用连字符分隔

### 内容原则

- 每个 SKILL 必须**自包含**，粘贴进 AI 对话框就能直接用
- 不依赖其他文件或外部工具
- 规则要具体可操作，不要空泛的建议
- 示例要贴近真实的论文场景

---

## 提交 Issue

使用以下模板：

### Bug / 规则错误
```
SKILL 文件：XX-XXX.md
问题描述：……
期望行为：……
使用的 AI 平台：Claude / ChatGPT / ...
```

### 功能建议
```
建议的功能：……
使用场景：……
参考来源（如有）：……
```
