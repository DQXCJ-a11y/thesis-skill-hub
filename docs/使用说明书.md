# 硕士论文审查 SKILL · 使用说明书

**适用对象：** 使用 Claude / ChatGPT / Gemini 网页版审查硕士论文的用户

**文件说明：** 本说明书配套 `SKILL.md` 使用，给人看的，不用发给 AI

---

## 一、你拿到了什么

| 文件 | 作用 | 怎么用 |
|------|------|--------|
| `SKILL.md` | 核心审查指令（约8000字） | 整段复制粘贴给AI |
| 本说明书 | 操作流程和注意事项 | 自己读，不用给AI |

---

## 二、三步快速上手

### 步骤1：复制 SKILL

打开仓库根目录的 `SKILL.md`，**全选复制**。

### 步骤2：新建 AI 对话并激活

打开 claude.ai 或 chatgpt.com，**新建对话**，第一条消息发送：

```
请你完整阅读以下工作指令，阅读完毕后只需回复「已就绪，请提供论文内容」，不需要其他解释：

【在这里粘贴SKILL.md全文】
```

**等 AI 回复"已就绪"后**再进行下一步。

> ⚠ 关键：不要在第一条消息里同时发 SKILL 和论文！AI 会跳过指令直接处理。

### 步骤3：上传论文并触发审查

```
以下是我的论文全文，请按照SKILL中的审查标准进行完整的13维度审查，输出格式严格按照第五章规定的格式。

【上传PDF/Word文件，或粘贴论文全文】
```

## 三、不同平台的差异

### Claude 网页版（推荐）

- 单次约 20 万 token，一篇硕士论文可以一次性全文审查
- 支持直接上传 PDF/Word 文件
- 推荐模型：Claude Sonnet 或 Claude Opus

### ChatGPT 免费版

- 上下文约 8k token，**必须分章处理**
- 每章新建一个对话，每次都要重新激活 SKILL
- 流程：新建对话 → 粘贴 SKILL → 等"已就绪" → 粘贴一章 → 审查 → 保存 → 换下一章

### ChatGPT Plus / GPT-4o

- 上下文更长，可以处理更多内容
- 仍建议分 2-3 次处理

## 四、审查后的操作建议

| 轮次 | 操作 | 目的 |
|------|------|------|
| 第一轮 | 用 SKILL 做全文审查 | 找到宏观问题和 🔴 必须修改项 |
| 第二轮 | 对问题最多的章节逐段深入 | 找到具体句子级别的问题 |
| 第三轮 | 对 AI 痕迹段落做润色 | 消除 AI 写作特征 |
| 第四轮 | 参考文献单独检查 | 格式、遗漏、时效性 |

---

## 五、常见问题

**Q：AI 说内容太长处理不了？**
分章发送。每章单独一个对话，每次重新激活 SKILL。

**Q：AI 没按格式输出？**
追加：`请严格按照SKILL第五章规定的表格格式输出，不要省略任何维度。`

**Q：和导师意见不一致？**
以导师意见为准。SKILL 是通用标准，导师了解你的具体情况。

**Q：可以用来写论文吗？**
可以参考附录B的句式模板，但 SKILL 主要功能是审查，不是代写。

## 六、局限性

1. 不能检查数据真实性（只能检查数据自洽性）
2. 不能替代导师审阅
3. 不能保证通过查重
4. AI 单次处理可能遗漏，建议做 2-3 轮
