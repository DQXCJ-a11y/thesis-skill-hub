# 使用指南

## 写在前面

这套 SKILL 是一组精心编写的 Prompt，你把它复制粘贴到任何 AI 对话界面里就能用。不需要安装任何东西，不需要会编程，不需要懂命令行。

---

## 支持哪些 AI 平台

| 平台 | 是否支持 | 备注 |
|------|---------|------|
| Claude（claude.ai） | ✅ | 推荐，长文本处理能力强 |
| ChatGPT（chatgpt.com） | ✅ | GPT-4o 及以上效果较好 |
| Gemini（gemini.google.com） | ✅ | |
| DeepSeek（chat.deepseek.com） | ✅ | 性价比高 |
| 通义千问（tongyi.aliyun.com） | ✅ | |
| 其他支持长文本的 AI 对话工具 | ✅ | |

所有 SKILL 在以上平台均可使用，但不同模型的输出质量可能有差异。如果发现某个平台效果不好，可以尝试换一个。

## 基本使用方法

### 第一步：选择 SKILL

根据你当前的需求，从以下列表中选择一个：

| 我的情况 | 用哪个 SKILL |
|---------|-------------|
| 刚开始，不知道做什么方向 | 01-选题调研 |
| 有了文献，想看懂它们 | 02-文献分析 |
| 选好题了，要写大纲 | 03-大纲生成 |
| 要开始写某一章 | 04-章节写作 |
| 写完了，想检查质量 | 05-全文审查 |
| 担心术语格式不统一 | 06-一致性检查 |
| 查重没过，要降重 | 07-降重改写 |
| 担心 AIGC 检测不过 | 08-AI痕迹消除 |
| 要写摘要或结论 | 09-摘要与结论 |

### 第二步：复制 SKILL 内容

打开对应的 `.md` 文件，**复制全部内容**。

### 第三步：粘贴到 AI 对话框

打开你常用的 AI 对话界面（Claude / ChatGPT / Gemini / DeepSeek 等），把复制的内容粘贴到对话框里，发送。

### 第四步：按 AI 的引导操作

AI 会告诉你接下来需要提供什么信息，按指示操作即可。

## 进阶用法

### 使用风格学习让输出更像你自己

1. 先用 `00-风格学习` 分析你的写作风格，生成"风格摘要"
2. 把风格摘要保存下来（复制到记事本/备忘录）
3. 以后用其他 SKILL 时，在粘贴 SKILL 内容之后，再粘贴一段：

```
以下是我的写作风格摘要，请在输出时参考：
（粘贴你的风格摘要）
```

### 组合使用多个 SKILL

由于每次新对话 AI 不记得之前的内容，所以每次使用都需要重新粘贴 SKILL。但你可以把之前的产出带过来：

- 用 01 确定了选题 → 把选题结果复制保存 → 用 03 时粘贴选题结果
- 用 03 生成了大纲 → 把大纲复制保存 → 用 04 时粘贴对应章节的大纲
- 用 07 降重后 → 把降重后的文本 → 用 08 进一步消除 AI 痕迹

### 处理长文本

大多数 AI 平台有输入长度限制。如果你的论文太长一次放不下：

1. **按章节分次提交**：每次只粘贴一章的内容
2. **告诉 AI 上下文**：在粘贴时说"这是第三章的内容，前面章节讨论了……"
3. **汇总结果**：各章审查完后，可以把所有审查意见汇总在一个文档里

## 常见问题

**Q：不同 AI 平台效果有差异怎么办？**
A：推荐使用 Claude 或 GPT-4o 及以上。如果某个平台效果不理想，换一个试试。SKILL 本身是通用的，但不同模型的理解和执行能力有差异。

**Q：可以在同一次对话中使用多个 SKILL 吗？**
A：不建议。每个 SKILL 都有独立的角色设定和工作流程，混在一起会让 AI 角色混乱。建议每个 SKILL 开一次新对话。

**Q：AI 输出的内容可以直接用吗？**
A：不建议。AI 输出的内容应该作为**初稿和参考**，你需要用自己的判断来审视、修改和补充。特别是数据和引用，必须自己核实。

**Q：使用这些 SKILL 算学术不端吗？**
A：这些 SKILL 的设计理念是"辅助"而非"代写"。它们帮你理清思路、发现问题、改善表达，但核心的研究工作和学术判断必须是你自己的。具体是否合规，请遵循你所在学校的相关规定。
