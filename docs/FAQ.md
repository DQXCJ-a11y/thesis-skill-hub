# 常见问题

## 基本使用

**Q：我需要安装什么软件吗？**
不需要。打开任意 AI 对话界面（Claude / ChatGPT / Gemini / DeepSeek / 通义千问等），把 SKILL 文件的内容复制粘贴进去就能用。

**Q：哪个 AI 平台效果最好？**
推荐 Claude（claude.ai）或 ChatGPT（GPT-4o 及以上），长文本处理能力和指令遵循能力较强。DeepSeek 性价比高，也能用。不同 SKILL 在不同平台上的效果可能有差异，可以多试几个。

**Q：免费版的 AI 能用吗？**
可以用，但免费版通常有输入长度限制和每日次数限制，对于长文本审查等场景可能不够用。建议至少使用基础付费版。

**Q：一次对话能用多个 SKILL 吗？**
不建议。每个 SKILL 有独立的角色设定，混用会导致 AI 角色混乱。建议每个 SKILL 开一次新对话。

## SKILL 选择

**Q：不知道该用哪个 SKILL？**
看你当前的痛点：
- 不知道做什么 → 01-选题调研
- 写完了不确定质量 → 05-全文审查
- 查重没过 → 07-降重改写
- 担心 AI 检测 → 08-AI痕迹消除
- 其他情况看 README 的对照表

**Q：07-降重改写 和 08-AI痕迹消除 有什么区别？**
07 侧重降低查重率（知网/维普等文字重复检测），08 侧重降低 AIGC 检测率（AI 生成文本识别）。两个是不同的问题，可能需要分别处理。建议先用 07 降重，再用 08 消除 AI 痕迹。

## 论文太长怎么办

**Q：我的论文有 3 万字，一次放不进去怎么办？**
按章节分次提交。大多数 SKILL 都支持逐章处理。在粘贴时简单说明上下文即可，比如"这是第三章，前面讨论了……方法，这一章是实验验证"。

**Q：全文审查需要一次性提交全文吗？**
不需要。可以逐章提交审查。但"一致性检查"（06）最好能提供多章内容，因为一致性问题本身就是跨章节的。

## 学术规范

**Q：用这些 SKILL 算学术不端吗？**
这些 SKILL 设计为辅助工具，帮你理清思路、发现问题、改善表达。核心的研究工作、数据分析、学术判断必须是你自己的。具体是否合规，请遵循你所在学校的规定。

**Q：AI 帮我改写的内容还会被查重查出来吗？**
有可能。07-降重改写 能显著降低重复率，但不能保证降到 0。改写后建议用学校指定的查重系统再检测一次。

**Q：用了 08-AI痕迹消除 就不会被 AIGC 检测出来吗？**
不能保证。08 能降低 AIGC 检测风险，但各检测工具的算法在不断更新。建议在正式提交前用学校指定的 AIGC 检测工具自查。
