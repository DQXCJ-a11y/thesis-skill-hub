## [v1.0.0] - 2025-03-10

### Added
- 首次发布 `SKILL.md`（综合3个开源仓库 + 自有写作指导手册）
- 来自 xstongxue/best-skills 的论文大纲审核、润色去AI味规则

- 来自 huangkiki/dailypaper-skills 的文献辅助验证思路
- 13项审查维度完整覆盖：
  1. 叙事主线与章节衔接
  2. 摘要四要素完整性
  3. 绪论深度审查（四段式 + 研究现状 + 创新点）
  4. 理论基础审查（四层结构 + 三个必答问题）
  5. 方案设计审查（架构图 + 选型论证 + 参数依据）
  6. 实现/进阶审查（承接说明 + 递进关系）
  7. 实验验证审查（四要素 + 对比基准 + 数据完整性）
  8. 总结与展望审查（与绪论对比 + 展望具体性）
  9. AI痕迹审查（8种特征识别）
  10. 格式与排版审查
  11. 参考文献审查（GB/T 7714-2015）
  12. 交叉引用审查
  13. 逻辑硬伤与数据自洽性检查
- 提交前全文自查清单
- 常用句式模板速查
- Claude / ChatGPT 网页版完整操作流程
