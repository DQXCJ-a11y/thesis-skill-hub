# 🎓 thesis-skill-hub

**面向中文理工科硕士论文的开源 AI 审查与写作辅助工作流**

本项目不是论文生成器，也不是单纯的 prompt 收集仓库。  
它更像一套可以直接复用的论文辅助工作流：帮你把论文审查、结构检查、章节修改、表达优化这些高频任务，整理成可直接投喂给 Claude / ChatGPT / Gemini 的 `SKILL.md`。

适用平台：Claude / ChatGPT / Gemini 网页版（无需 CLI、无需编程）

---

## 这是什么？

很多人在写硕士论文时都会遇到同样的问题：

- 不知道论文结构有没有问题
- 不知道每一章到底该怎么写
- 不知道 AI 生成内容哪里“像 AI”
- 不知道把论文丢给大模型后，怎样才能让它真正按论文标准审查，而不是只给一些空泛建议

GitHub 上虽然已经有一些优秀的论文写作相关 skill、prompt 和规则文件，但它们通常分散在不同仓库里，风格不一致，能力边界不清晰，普通用户很难直接拿来稳定使用。

**thesis-skill-hub 想解决的，不是“有没有 prompt”，而是“如何把论文辅助这件事变成一套普通学生也能稳定复用的工作流”。**

本项目当前核心内容是：

- 收敛并整理论文场景下真正有用的审查规则
- 将分散的 skill 合并为一份可直接使用的 `SKILL.md`
- 让用户无需编程，也能把论文 PDF 交给大模型做相对规范的辅助分析
- 持续迭代适合中文理工科硕士论文的审查与修改流程

---

## 这个项目适合谁？

本项目主要面向以下用户：

- 正在写中文硕士毕业论文的学生
- 尤其是理工科、工科方向的论文写作者
- 想借助 Claude / ChatGPT / Gemini 做论文辅助检查的人
- 不想折腾复杂工具链，只想“复制 → 上传 → 开始分析”的普通用户

如果你最需要的是：

- 论文整体结构检查
- 各章节内容是否跑偏
- 逻辑链条是否顺
- 语言表达是否空泛
- AI 痕迹是否明显
- 修改意见是否更具体可执行

那这个项目会比较适合你。

---

## 这个项目不是什么？

为了避免误解，这里把边界说清楚：

**本项目不是：**

- 不是自动代写论文工具
- 不是正式查重系统
- 不是学术不端规避工具
- 不是导师意见替代品
- 不是保证“论文一定过”的神器
- 不是保证研究创新性判断准确的系统

**本项目能做的是论文辅助，不是学术责任替代。**  
它更适合作为你写作和修改过程中的一个“辅助检查器”和“对话式工作流”。

---

## 它和直接问大模型有什么区别？

直接把论文发给大模型当然也能得到回答，但问题通常是：

- 回答不稳定
- 审查标准不统一
- 经常只给空泛建议
- 不会按论文章节去看问题
- 很难重复复用
- 不同平台、不同会话下表现波动很大

本项目的价值不在于“发明了一个更聪明的 AI”，而在于：

**把论文辅助这件事，整理成一套更稳定、更可复用、更适合普通用户的输入方式。**

也就是说，这里的重点不是“模型变强了”，而是“工作流变清楚了”。
