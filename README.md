# 🎓 thesis-skill-hub

**面向中文理工科硕士论文的开源 AI 审查与写作辅助工作流**

---

## 项目定位

本项目不是论文生成器，也不是 prompt 收集仓库，而是一套可直接复用的论文辅助工作流——将论文审查、结构检查、章节修改、表达优化等高频任务，整理成可直接投喂给 Claude / ChatGPT / Gemini 的 `SKILL.md`。

**适用平台：** Claude / ChatGPT / Gemini 网页版（无需 CLI，无需编程）

---

## 解决什么问题？

很多学生写硕士论文时都面临以下困惑：

- 论文结构有没有问题？
- 每一章该怎么写？
- AI 生成内容哪里"像 AI"？
- 怎样让大模型真正按论文标准审查，而不是只给空泛建议？

本项目的价值在于：**把论文辅助这件事，整理成一套更稳定、更可复用、更适合普通用户的输入方式。**

---

## 适合谁？

- 正在写中文硕士毕业论文的学生
- 理工科、工科方向的论文写作者
- 想借助 AI 做论文辅助检查，但不想折腾复杂工具链的普通用户

**核心能力覆盖：**

- 论文整体结构检查
- 各章节内容是否跑偏
- 逻辑链条是否顺畅
- 语言表达是否空泛
- AI 痕迹是否明显
- 修改意见是否具体可执行

---

## 不是什么？

| ❌ 不是 | ✅ 是 |
|--------|------|
| 自动代写工具 | 辅助检查器 |
| 正式查重系统 | 对话式工作流 |
| 导师意见替代品 | 写作修改过程中的参考工具 |
| 保证论文通过的工具 | 帮你发现问题的助手 |

## 30 秒上手

1. 打开 `SKILL.md`，全选复制
2. 打开 claude.ai / chatgpt.com / Gemini，新建对话
3. 发送以下内容：

```
请你完整阅读以下工作指令，阅读完毕后只需回复「已就绪，请提供论文内容」：

【粘贴 SKILL.md 全文】
```

---

## 推荐使用方式

**方式一：整篇审查**（适合先看整体问题）
```
请按照 SKILL 中的标准，对这篇论文进行完整审查，
并按"整体问题 + 分章节问题 + 优先修改建议"的结构输出。
```

**方式二：单章精修**（适合集中修改某章）
```
请重点审查第3章，只指出逻辑、结构、表达和方法描述上的问题，
并给出可直接修改的建议。
```

**方式三：答辩前总检查**（适合论文基本成型后）
```
请从论文结构完整性、章节衔接、表达规范性、AI痕迹风险、
摘要与结论一致性几个方面做一次总检查。
```

## 开源原则

- **实用优先**：解决真实写作中最常见的问题
- **边界清晰**：不夸大 AI 能力
- **普通人可用**：不依赖编程和复杂环境
- **持续迭代**：根据反馈不断调整
- **开放协作**：欢迎提交问题、经验和改进建议
